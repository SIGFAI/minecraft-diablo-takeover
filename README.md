# Diablo Takeover

**Minecraft** × Diablo · visual · idea by the team

Bring Diablo into the game in the most visible and funny way. The change shows in the first 30 seconds of play.

> Built Diablo Takeover: Minecraft turns into Tristram with loot beams, damage numbers, Hell Bovines and a Whirlwind barbarian. The cow level is real.

## Install

Install Fabric Loader and Fabric API for Minecraft Java 26.3, then drop the Diablo Takeover mod jar into your mods folder. Start a world: night falls, demons attack, and the Doombringer sword (right-click for Whirlwind) drops from bosses.
